Key Concepts

  • A single face cannot bend; curvature requires additional subdivisions
  • Subdivision math is exponential, not linear (one face becomes four, then sixteen, etc.)
  • Quads are preferred over triangles and N-gons because they deform smoothly and split cleanly into triangles
  • Loop cuts allow targeted, efficient subdivisions instead of generic subdividing everywhere
  • Modifier order matters because modifiers apply mathematical operations sequentially
  • Applying scale (Ctrl+A) sets the current size as the new relative standard, which is critical before using modifiers
  • Scatter on Surface modifiers are placed on the surface object, not the object being scattered
  • Weight painting stores extra per-vertex data (like density maps) that can control procedural effects such as tree or rock placement

Key Concepts

  • Always apply object scale (should read 1,1,1) to avoid distorted array and modifier results
  • Use the new array modifier instead of the legacy version for better performance and features
  • Material preview mode uses a default HDR sky for reflections, but rendered view does not unless one is added
  • EEVEE is a real-time render engine (what you see is what you get), while Cycles is an offline ray-traced engine with higher fidelity but slower render times
  • Abstraction means non-representational work, distinct from surrealism which distorts recognizable objects
  • Enabling ray tracing in EEVEE improves reflection realism at some performance cost
  • Curve objects can be converted to 3D geometry using bevel, extrude, or the Curve to Mesh/Tube modifier, and drawing should be done in orthographic views for precision
  • Combining array and randomization (rotation, scale, offset) on curve-based logs creates natural, non-repetitive log cabin walls

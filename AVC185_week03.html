Key Concepts

  • Weight painting stores per-vertex data that can drive scatter density, scale, or rotation parameters
  • Subdividing geometry increases resolution for finer weight paint control, while procedural subdivision modifiers don't affect vertex painting
  • Object origin (anchor point) placement is critical for correct scaling and rotation behavior
  • Curve-to-tube and solidify modifiers convert flat curves or planes into 3D geometry like logs, twigs, and shingles
  • Shade Auto Smooth is a modifier with an adjustable angle threshold, offering more control than Shade Smooth/Flat, with Mark Sharp providing the finest edge-level control
  • Grease Pencil can draw connected 3D curves in draw/stroke mode, then be converted to mesh and curve objects for organic shapes like tree branches
  • Convert to Mesh bakes procedural modifiers into editable geometry, useful before combining objects across scenes for performance
  • Ctrl+L (Link) applies materials or modifiers to multiple selected objects, with the last-selected object acting as the source

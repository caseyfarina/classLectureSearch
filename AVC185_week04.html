Key Concepts

  • VR headset setup requires per-computer, per-student configuration via Software Center and Vive Streaming
  • Headsets charge via a separate charging station, not through the data-only USB cable
  • Stereoscopic vision requires rendering two separate camera views (one per eye), doubling computation cost
  • 360 panoramas and videos let viewers look around pre-rendered scenes without needing Blender or a live VR session
  • Subdivision surface modeling smooths simple low-poly meshes using the Catmull-Clark algorithm
  • Controlling edges (via loop cuts, insets, and extrudes) let you selectively sharpen areas of an otherwise smooth mesh
  • Subdivision surface modeling works best with quad topology; triangles and n-gons cause shading problems
  • Level of detail (smoothness) should match how much space an object takes up in the camera frame, not its absolute size

Key Concepts

  • Cylinder primitives default to 32 subdivisions, which is often excessive for simple objects
  • Cones are poor candidates for subdivision surface modeling due to triangle and n-gon topology
  • The 'Realize Instances' checkbox determines whether array-generated geometry can be further modified or converted to mesh
  • Weight painting is an effective way to control density of scattered objects like trees and stones
  • Metaballs create smooshy, organic blob shapes that must be converted to mesh before using standard modifiers
  • Combining an emissive material with an actual light object sells convincing light sources like lanterns and lamps
  • The Inset Faces tool with 'Individual' enabled allows insetting multiple selected faces independently
  • Compositing bloom/glow adds a professional finishing touch to emissive elements in a render
  • Extrude Along Normals and Individual Origins scaling are key tools for building radial shapes like a bundt cake

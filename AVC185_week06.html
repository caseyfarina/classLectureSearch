Key Concepts

  • Materials are composed of separate channels (color, roughness, metallic, normal, alpha) that can be driven by a single value, an image texture, or a procedural shader
  • Eevee and Cycles share the same material system in Blender, so materials don't need to be rebuilt when switching render engines
  • Image textures require correct color space settings: sRGB for color data, Non-Color for scalar data like roughness or metallic maps
  • Normal maps store XYZ angle data in RGB channels to fake surface bumpiness without adding geometry, and must pass through a Normal Map node
  • Procedural shaders (noise, Voronoi, dent noise) generate infinitely scalable detail from code, unlike finite-resolution image textures
  • Color ramps and invert nodes let you remap and adjust scalar texture data without losing per-pixel detail, similar to adjustment layers in Photoshop
  • Node Wrangler's Ctrl+T and Ctrl+Shift+T shortcuts speed up setting up texture projections and auto-importing full texture sets
  • Texture resolution should match how large an object appears in frame, and unnecessary textures or channels cost performance and VRAM

Key Concepts

  • Normal maps go directly into a Normal node, while height/bump maps must pass through a Bump node before reaching the Normal channel
  • Drivers using #frame create continuous automatic animation without manual keyframes, ideal for constant-speed motion like water or windmills
  • Dividing the frame number in a driver expression slows animation speed; multiplying speeds it up
  • Triplanar (box) projection blends textures from three planes to evenly cover objects lacking UV unwrapping
  • Prioritize downloading color/diffuse and normal maps first when sourcing textures; roughness is secondary
  • Match texture tiling scale to the object's real-world size to avoid unrealistic patterns
  • Cinematic camera moves should be slow and linear; contrasting direction between shots improves visual flow
  • Reduce render time by lowering resolution percentage or disabling volumetrics if frames take too long to render

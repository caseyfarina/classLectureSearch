Key Concepts

  • Use equirectangular (2:1 aspect ratio) textures for spherical planet wraps
  • Height maps feed into Bump nodes, while normal maps feed directly into the Normal channel—never mix both into one
  • Color Ramp nodes are useful for cranking contrast to create clean masks (e.g., separating land from water)
  • Displacement actually moves geometry and requires enabling displacement in material settings plus adequate mesh subdivision
  • Layering high-frequency and low-frequency noise creates more believable procedural surface detail
  • Fresnel nodes detect edges/viewing angle and are key for atmosphere glow and fade-out effects
  • Drivers using #frame expressions enable smooth, consistent animation like planet rotation and cloud drift
  • Compositing nodes (Bloom, Glare, Alpha Over) can stylize renders beyond what the 3D shader alone provides

Key Concepts

  • The hashtag-frame driver with fluid noise nodes has a known bug causing scale resets on save; the built-in Asset Browser water material avoids this issue
  • Shot pacing should match real-world scale: larger structures require slower camera movement to feel believable
  • Use the compositor's waveform scope to check image brightness and apply color correction (gamma, gain, offset) to recover detail in dark renders
  • Volumetric fog becomes more realistic by driving density with Perlin/noise textures and a color ramp for contrast control
  • Tri-planar projection must be applied consistently across all texture channels (color, roughness, normal) to avoid misaligned scale
  • Visible light sources (spheres with emission) should have ray visibility shadows turned off so they don't block their own light
  • Boolean modeling works with signed distance fields, allowing fast shape roughing that can then be converted to clay and sculpted with symmetry
  • When exporting meshes, prefer quads over triangles for rigged/deforming objects, and manage triangle count for performance

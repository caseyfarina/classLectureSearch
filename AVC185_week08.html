Key Concepts

  • UV space is a normalized 2D coordinate system (0 to 1) describing where pixels map onto 3D faces
  • UV unwrapping is like wrapping Christmas presents or flattening a cardboard box - flat 2D paper onto 3D shapes causes distortion
  • A UV seam defines where geometry can separate in UV space while remaining connected in 3D space, creating UV islands
  • Good UV maps minimize distortion, avoid unwanted overlapping faces, and maximize pixel usage (texel density)
  • Overlapping UVs cause painting to appear simultaneously on multiple faces, which is usually undesirable except for repeating patterns
  • UV packing (adjusting island scale and layout) happens after unwrapping to optimize pixel usage within UV space
  • Smart UV Project automatically generates seams, while manual seam marking with Live Unwrap gives more control
  • Substance Painter requires baked mesh maps (normal, curvature, AO, thickness) for smart materials to interact correctly with mesh shape
  • USD export/import between Blender and Substance Painter greatly simplifies round-tripping materials and textures

Key Concepts

  • A manifold mesh must have no holes so it can theoretically hold water, which is required for 3D printing
  • STL files export geometry while G-code contains the actual print head movement instructions
  • Infill percentage and brim settings control print time and adhesion to the print bed
  • Height/bump maps must be set to non-color space, while only base color textures use sRGB
  • Boolean intersect can be used to create clean, square-edged geometry instead of just the usual difference operation
  • Camera movement and fog/wave animation speed in cinematic shots are usually too fast and should be slowed down significantly
  • Scene time in seconds with a Map Range node avoids driver errors that occur when animating with frame-based expressions
  • Voronoi texture noise is a versatile base for rock, ice, and cellular breakup patterns

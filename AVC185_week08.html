Key Concepts

  • A manifold mesh must have no holes so it can theoretically hold water, which is required for 3D printing
  • STL files export geometry while G-code contains the actual print head movement instructions
  • Infill percentage and brim settings control print time and adhesion to the print bed
  • Height/bump maps must be set to non-color space, while only base color textures use sRGB
  • Boolean intersect can be used to create clean, square-edged geometry instead of just the usual difference operation
  • Camera movement and fog/wave animation speed in cinematic shots are usually too fast and should be slowed down significantly
  • Scene time in seconds with a Map Range node avoids driver errors that occur when animating with frame-based expressions
  • Voronoi texture noise is a versatile base for rock, ice, and cellular breakup patterns

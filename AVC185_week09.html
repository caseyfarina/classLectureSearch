Key Concepts

  • High-to-low poly baking transfers sculpted detail from a heavy mesh into normal, curvature, and AO maps on a lightweight, game-ready mesh
  • A proper bake requires a sculpted high poly mesh, a matching-silhouette low poly mesh, and clean UVs with packed islands
  • Average Island Scale balances UV space allocation so small and large parts get proportional texture resolution
  • The bake cage distance determines what high poly detail is captured; too small a cage causes errors and artifacts
  • Triplanar projection avoids visible seams when projecting tiling materials onto unwrapped UVs
  • Smart materials and smart masks use baked mesh map data (curvature, AO, world normals) to dynamically generate realistic wear and texture patterns
  • Masking can be done by hand-painting, using mesh/UV chunk fills for clean boundaries, or using procedurally generated smart masks
  • Each texture channel (color, height, normal, roughness) has its own blend mode, which explains why underlying detail can show through or get covered unexpectedly

Key Concepts

  • UV seams should follow a 'cardboard construction' mental model—imagine how the object would unfold if built from flat material
  • Avoid excessive seams; use the minimum necessary cuts to let geometry lay flat without distortion
  • Always check for overlapping UV islands, which prevent proper individual texturing of a surface
  • USD (Universal Scene Description) is a non-proprietary format meant to simplify transferring textured models between programs like Substance Painter and Blender
  • Control+Shift+T in Blender with Node Wrangler automatically wires texture folders to shader inputs
  • UV unwrap simple geometry before applying modifiers like Subdivision Surface to avoid added complexity
  • In Substance Painter, fill layers with masks are more flexible and adjustable than direct paint layers
  • Blur and Bevel filters on height-channel masks create smoother, more realistic surface detail

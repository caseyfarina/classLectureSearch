Key Concepts

  • Kit bashing is the practice of assembling models from parts of other kits or models, originating from practical effects in films like Star Wars
  • Greebles are the small detail pieces added to a larger form to suggest complexity and scale
  • Design decisions should be driven by a vehicle's narrative purpose, letting form follow function
  • Deciding what detail belongs in the mesh versus the texture (height/normal maps) is a key modeling skill
  • Anchor points in Substance Painter let you read painted height data from one layer into a mask generator on another layer, merging painted and geometric detail
  • Micro height and micro normal settings must be manually set to true to activate anchor point data in smart materials
  • Stacking UV islands intentionally allows repeated parts (like fan blades) to share texture space efficiently
  • Applying scale issues can break modifiers; use Apply Scale or Smart Apply Scale to fix unexpected behavior

Key Concepts

  • Manifold checks and warnings indicate mesh properties to evaluate, not errors that always must be zeroed out
  • Separating objects into parts and reorienting them reduces the need for complex overhang support structures
  • Emission strength and emission color are independent settings; both must be configured for a proper glow effect
  • Post-processing effects like bloom/glare are required to visualize emission beyond simple brightness
  • Merge by distance resolves overlapping vertices that create zero-area faces and printing errors
  • Anchor points store mesh or layer data that can be read by smart materials above them in the layer stack
  • The Decimate modifier can reduce polygon count created by subdivision surfaces for faster print processing
  • UV islands need sufficient pixel space to avoid stretched or blurry textures on larger surface areas

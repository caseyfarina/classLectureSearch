Key Concepts

  • In-person attendance and live online participation are the two available modalities; asynchronous self-paced work is no longer offered
  • Weekly projects make up 75% of the grade, with the final portfolio review comprising the remaining 25%
  • External hard drives and dedicated GPU computers are required for handling heavier graphics work
  • Discord is for course content and peer questions; email is reserved for personal academic issues
  • AI tools are used transparently by the instructor to build course materials, but students are not required to use AI directly
  • Unity enables non-linear, interactive experiences (games, VR/AR) unlike linear animation tools like Blender or After Effects
  • Real-time rendering (measured in frames per second) differs fundamentally from offline rendering (measured in seconds per frame) used in animation
  • Changes made during Unity's play mode are not permanent to the underlying project structure

Key Concepts

  • Unity 'builds' compiled applications rather than 'rendering' videos like Blender
  • PNG files support an optional alpha channel for transparency, unlike JPEG
  • Always use the free personal Unity account, not the academic/student option, and set install path one level above the Assets folder
  • Packages extend Unity's functionality similarly to add-ons in Blender
  • LTS (Long-Term Service) versions of software are more stable for consistent, dependable work
  • Pivot vs. center anchor points affect how objects are moved and manipulated in the scene
  • Perspective view shows realistic depth while isometric/orthographic view preserves true scale for precise placement
  • Realistic bounce animation requires accelerating curves, not symmetric ease-in/ease-out, to mimic gravity
  • Changes made while in Play Mode are not saved and will be lost when exiting Play Mode
  • Unity Events let objects communicate by specifying which object receives a message and what function it should call

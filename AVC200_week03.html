Key Concepts

  • Blender uses Z-up while Unity uses Y-up, requiring axis correction on export
  • Always apply scale in Blender so imported meshes have a relative scale of 1,1,1
  • The Delivery Kit Blender add-on simplifies correct FBX export for Unity
  • 3D mesh anchor points must be set before export, while sprite anchor points (pivots) can be changed anytime in Unity
  • Sprites require setting texture type to Sprite and mode to Single or Multiple depending on use
  • Sorting layers control front/back rendering of sprites independent of camera distance
  • Frame-by-frame animation is created by dragging multiple sprite frames into the scene at once
  • Combining 2D sprites at different depths in a 3D scene creates a parallax (2.5D) effect

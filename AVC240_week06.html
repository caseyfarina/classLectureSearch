Key Concepts

  • Frame rate is an artistic/stylistic decision, not just a technical one
  • Hand-drawn animation historically used lower FPS (12 fps 'on the twos', 8 fps 'on the threes') to reduce drawing workload
  • An image sequence has no inherent frame rate; it must be interpreted correctly in compositing software
  • When combining multiple frame rates in one composition, the container frame rate must be greater than or equal to the maximum frame rate used
  • Quantization (stepped keyframes) can simulate lower frame rates without changing underlying keyframe data
  • Cultural associations with frame rate (24fps as 'cinematic', 30/60fps as 'soap opera' or 'video game' smoothness) are learned, not inherent
  • Three NPR toon-outline techniques: reverse hull (inverted normals mesh), grease pencil line art, and Fresnel-based shader outlines
  • Animation boil refers to subtle frame-to-frame variation that can convey 'aliveness' or be deliberately removed for efficiency (e.g., Pokemon-style animation)

Key Concepts

  • Wider aspect ratios feel more cinematic because they mimic human peripheral vision and evoke grandiose, epic scale
  • Changing aspect ratio requires reframing and relighting shots, not just cropping the image
  • Pixel aspect ratio in Blender should always stay 1:1; use the resolution/aspect ratio settings instead to avoid distorted renders
  • Camera shake done with 2D wiggle effects needs a mask or black border so the frame edges don't visibly move, unlike true 3D camera animation
  • Stepped interpolation modifiers simulate lower frame rates, but must be applied correctly across all bones using NLA actions rather than individual key frames
  • Bone selection behavior in Blender's graph editor changes based on what's selected when pressing 'Select All', affecting access to modifiers
  • Grease pencil line art combined with toon shaders (via Shader to RGB and color ramps) creates a non-photorealistic rendering style
  • Mark Sharp edges control where grease pencil outline strokes appear on a mesh

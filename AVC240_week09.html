Key Concepts

  • The 180 degree rule keeps the camera on one side of an imaginary line between characters to prevent audience disorientation
  • Breaking the 180 degree rule can be used intentionally to create disorientation as a narrative effect
  • A typical dialogue scene uses an establishing two-shot plus over-the-shoulder shots for each character
  • Audio recorded in Adobe Audition produces both a project file and a separate wave file needed for import
  • In Blender's NLE, animations must be pushed down into strips and placed on separate tracks to mix multiple actions on one character
  • Blend values are required on animation strips or newer actions will completely override earlier ones with no transition
  • Custom meshes must be joined into a single continuous mesh before uploading to Mixamo for auto-rigging
  • Depth of field and longer focal lengths help focus attention on the speaking character during cuts

Key Concepts

  • Composition elements (point, line, shape, depth, balance, color, pattern, texture) work together simultaneously in any image rather than appearing in isolation
  • Depth of field can be used both as a stylistic camera technique and practically to hide low-resolution textures
  • Balance in composition is about understanding visual weight distribution, not strict symmetry
  • Studying real-world film and game references and 'reverse engineering' why a shot works is a powerful way to improve personal composition skills
  • Render time budgeting matters: students must balance visual style ambitions against practical rendering constraints
  • The 180-degree rule keeps camera placement consistent on one side of an imaginary line between characters to maintain spatial continuity
  • An NLA audio visualizer add-on simplifies syncing animation and dialogue timing in Blender
  • Students take on multiple roles (director, voice actor, cinematographer, render wrangler) and must manage trade-offs like a producer managing budget
